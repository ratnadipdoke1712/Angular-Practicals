## About This Repository

This repository contains my Angular practical programs completed as part of the **FSD-III** course.

The practicals demonstrate important Angular concepts such as:

- String Interpolation
- Displaying Lists using Arrays
- One-Way Data Binding
- Student Portfolio
- Two-Way Data Binding
- Angular Routing
- Route Parameters

---

## Angular Practicals

### Practical 03 - String Interpolation

Demonstrates Angular string interpolation by displaying dynamic data from a component class.

**Concepts:**
- String interpolation
- Component properties
- Expressions
- Method interpolation
- Date pipe

---

### Practical 04 - Student List

Displays a list of 10 student names using an Angular array and `*ngFor`.

**Concepts:**
- Arrays
- `*ngFor`
- Data display

---

### Practical 05 - Time Table

Creates a weekly timetable using one-way data binding.

**Concepts:**
- One-way data binding
- Arrays
- Nested `*ngFor`
- Tables

---

### Practical 06 - Student Portfolio

Creates a student portfolio using Angular components and data binding.

**Concepts:**
- Component
- Object and arrays
- Interpolation
- `*ngFor`
- Property binding

---

### Practical 07 - Two-Way Data Binding

Demonstrates two-way data binding using `[(ngModel)]`.

**Concepts:**
- Two-way data binding
- `FormsModule`
- `ngModel`
- Interpolation

---

### Practical 08 - Angular Routing

Demonstrates basic Angular routing between different components.

**Concepts:**
- Angular Router
- Routes
- `routerLink`
- `router-outlet`
- Components

---

### Practical 09 - Route Parameters

Demonstrates defining route parameters and retrieving parameter values inside a component.

**Concepts:**
- Route parameters
- `ActivatedRoute`
- `paramMap`
- Dynamic routes
